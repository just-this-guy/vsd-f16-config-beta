VSD F16 Config Beta

rearanged icons to more closely match Block 50 layout

Extract the ZIP and run VSD F16 Config Beta.exe from the top-level folder.
Close VSD Craft and the simulators first. Back up any layout you have edited.

Choose BMS, DCS, or both, and the panels you use. Check prerequisites, review
and edit the shortcuts, then review your choices and apply.

DCS needs DCS Interface by Charlie Tytler and DCS-ExportScript; the installer
includes links. BMS must have keyboard focus when using the buttons.

BMS icons remember commands sent through VSD, so mouse/HOTAS changes can leave
them out of sync until another successful button press. DCS uses cockpit feedback.

This is an informal, unsigned beta. Expect rough edges.
